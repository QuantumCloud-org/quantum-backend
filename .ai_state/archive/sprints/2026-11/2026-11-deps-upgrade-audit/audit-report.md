## 覆盖与验证

- JWT 检查签发、验签、有效期、缓存撤销、刷新及 Cookie。MCP 检查模块开关、OAuth 客户端和回调地址、资源及 PKCE 绑定、Bearer 与 scope、工具权限。服务间缓存刷新与轮换缺口见 A02。
- SQL 检查业务 mapper XML、注解及 MyBatis-Flex 字符串入口。动态取值使用绑定参数。数据域的原生条件拼接来自代码内字段、别名和 `Long` ID，源码中未找到请求字符串到原生 SQL 字符串的链路。业务侧用户查询的 `@DataScope` 与按 ID 的读写守卫已交叉检查。
- 出站请求检查 S3、JDBC、Redis 和 OAuth 跳转。S3 SDK 目标来自服务配置，上传对象键不决定网络目标。OAuth 跳转前服务端检查登记的精确回调 URI，跳转由客户端跟随。本次源码核查未找到请求 URL 到服务端出站目标的路径。
- 定向红阶段为缓存、文件、日志、ORM 的 7 项失败，MCP 的 2 项失败，JWT 的 3 项失败。最终 `mvn clean test` 通过，含 12 项新增用例，合计 113 项。外部数据源、生产 Origin 和性能容量均待实环境验证。
